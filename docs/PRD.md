# Lava web page: PRD (template phase)

## Goal
A one-page website for the band **Lava** (spiritual music). For now a
template with filler text; the band's real wishes come later.

## Look and feel
- Apple-style scroll storytelling: the page reacts to scrolling.
- Hero: the brand name "LAVA" filled with flowing, glowing lava (animated,
  shader/canvas or video-like loop; WebGL if it stays smooth on phones).
- Scrolling moves the lava (flow, speed, colour shift), sections fade/parallax in.
- Dark background, lava palette (deep red, orange, yellow glow). Big type.
- Mobile first, desktop great too. `prefers-reduced-motion`: calm static lava.

## Sections (filler text)
1. Hero: LAVA + tagline
2. About: spiritual music, what the band does
3. Instruments: handpan, percussion, drums, singer (one card each)
4. Music: placeholder player/links (Spotify/YouTube later)
5. Live / dates: placeholder list
6. Contact / booking: placeholder email, social links
7. Footer (imprint/privacy placeholders)

## Out of scope
Backend, shop, CMS, user accounts, real media.

## Done when
Runs locally, smooth on a phone, all copy editable in one file, builds to
static files that can go to GitHub Pages or Cloudflare Pages later.

## Open questions (ask the band)
Real texts, photos, audio/video, tour dates, colours/logo, domain, languages.
